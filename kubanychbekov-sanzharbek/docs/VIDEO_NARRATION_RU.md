## Что реально, что ускорено, что скрыто
- **Реально:** все экраны (web в Chrome, телефон POCO по adb/scrcpy, консоль с тестами); заявка #96 создана, назначена, принята, выполнена, закрыта с оценкой 5, проверено в PostgreSQL. Офлайн: `docker compose stop backend`, затем `start`; в БД ровно одна копия офлайн-заметки.
- **Ускорено (подписано «Ускорено ×N»):** только ожидания и набор текста: вход и принятие на телефоне ×1.5–2, набор заметок ×2.5–3, выбор фото ×1.5–2, пауза скролла в web ×2.5, ожидание прогона backend-тестов ×6.
- **Скрыто/обрезано:** строка состояния телефона обрезана (личные значки); окно галереи с личными фото целиком размыто; пароли показаны точками; токены не показываются.
- **Нюансы честно:** текст заметок набран нажатиями по русской клавиатуре Gboard (adb не печатает кириллицу); при первой записи телефона файл MP4 повредился, поэтому вся цепочка записана заново на новой заявке (#95 завершена, #96 — финальная); в консоли тестов видны строка «Invalid parameter - cols» (необязательная настройка окна) и путь проекта; Flutter показал 38 пройденных тестов (в docs/VERIFICATION.md — 37, вероятно, устарело).
